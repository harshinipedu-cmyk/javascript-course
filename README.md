## Running the Code

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/javascript-course.git
   ```
2. Open any `.html` file in your browser, or run a `.js` file with Node.js:
   ```bash
   node filename.js
   ```
